# Deskassistant

## Introduction
Deskassistant is a compact device designed to help you increase your productivity. Placed on your desk, it keeps track of your priorities for the day and the time spent for each one. This project was presented as my graduation thesis for Computer Engineering Bachelor's Degree at Faculty of Mathematics and Computer Science, University of Bucharest.

## Repository structure
This repository contains the following:
- the software application written in QT
- PCB design for the connection board between Raspberry Pi Compute Module 5 and the rest of the peripherals (LCD display, touchscreen input, side buttons, brightness control, USB 2.0 interface)
- 3D design for the case backplate
- information about the OS-level configuration
